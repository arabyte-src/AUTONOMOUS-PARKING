# Parking Area YOLO Dataset

Synthetic dataset for a one-class YOLO object-detection task.

Class:
- 0: parking_area

Splits:
- train: 280 images
- valid: 80 images
- test: 40 images
- total: 400 images

Each image has one YOLO-format bounding-box annotation around a rectangular taped parking area.

Important:
This dataset is synthetic and should be supplemented with real photographs of the actual rectangular tape setup for final real-world evaluation.
